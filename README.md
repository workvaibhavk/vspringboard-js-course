## 🚀 How to Get Started — Step by Step

### Step 1 — Fork this repo
Click the **Fork** button at the top right of this page.  
This creates your own copy of the repo under your GitHub account.

### Step 2 — Clone your fork
```bash
git clone https://github.com/YOUR-USERNAME/vspringboard-js-course.git
cd vspringboard-js-course
```

### Step 3 — Create your folder
Inside the `students/` folder, create a folder with your name (no spaces, use hyphens).

```
students/
└── your-name/        ← create this
```

Example: `students/rahul-patil/` or `students/priya-desai/`

### Step 4 — Do tasks as you watch videos
Each video that has a task will have a folder inside `tasks/video-XX/task.md`.  
Read the task, then do it inside your own folder:

```
students/
└── your-name/
    ├── video-01/
    │   └── index.js
    ├── video-02/
    │   └── index.js
    └── ...
```

### Step 5 — Commit and push regularly
After completing each task, push it to your fork:

```bash
git add .
git commit -m "Completed task for video 03"
git push
```

### Step 6 — Final Pull Request
After video 24, open a **Pull Request** from your fork to this main repo.  
Your PR title should be: `[Your Name] — Course Completed`
